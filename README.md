# Химоид · Полные названия

**Интерактивный химический конструктор**  
Создавайте соединения, перетаскивая элементы из периодической таблицы. При наведении — полное название на русском.

---

## Возможности

- **Периодическая таблица** — все 118 элементов.
- **Создание объектов** — клик по элементу в таблице.
- **Перетаскивание** — перемещайте объекты по рабочему полю.
- **Соединение** — при перетаскивании одного объекта на другой они объединяются.
- **Полное название** — при наведении на объект показывается:
  - русское название элемента или соединения;
  - группа, атомная масса, валентность;
  - для соединений — состав и сгенерированное название (оксид, гидрид, хлорид и т.д.).

---

## Управление

| Действие | Результат |
|----------|-----------|
| **Клик** по элементу в таблице | Создаёт объект в центре рабочей области |
| **Перетаскивание** объекта | Перемещает его по полю |
| **Перетаскивание** одного объекта на другой | Объединяет их в одно соединение |
| **Наведение** на объект | Показывает подсказку с полным названием и свойствами |

---

## Примеры соединений

| Состав | Генерируемое название |
|--------|------------------------|
| `H` + `O` | Оксид водорода |
| `H` + `Cl` | Хлорид водорода |
| `Na` + `Cl` | Хлорид натрия |
| `C` + `O` | Оксид углерода |
| `N` + `H` | Гидрид азота |

---

## Технические детали

- **Язык**: чистый JavaScript (без библиотек)
- **Стили**: CSS с тёмной темой
- **Адаптивность**: поддерживает мышь и сенсорный ввод
- **Данные**: встроенная база элементов с названиями, массами, группами и валентностями

---

## Как это работает

1. При клике на элемент в таблице создаётся объект с его символом.
2. Объекты можно перетаскивать — они фиксируются в новой позиции.
3. При перетаскивании одного объекта на другой:
   - оба удаляются;
   - на их месте создаётся новый объект с составом из двух символов;
   - для нового объекта генерируется русское название.
4. При наведении показывается подробная подсказка.

---

## Структура данных

Каждый элемент имеет:
- `symbol` — химический символ (H, He, Li ...)
- `name` — английское название
- `rus` — русское название
- `mass` — атомная масса
- `group` — группа (неметалл, щелочной металл, галоген и т.д.)
- `valence` — валентность (используется для определения возможности соединения)

---

## Ограничения

- Соединения образуются только между элементами с ненулевой валентностью.
- Генерация названий использует упрощённые эвристики (оксиды, гидриды, хлориды, фториды).
- Сложные соединения (более 2 элементов) отображаются как перечисление с пометкой «сложное соединение».
