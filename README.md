## Основные возможности

### 1. Периодическая таблица
- **Клик** по элементу создаёт его на рабочем поле
- **Наведение** показывает подробную информацию:
  - Название и символ
  - Атомный номер и масса
  - Валентность
  - Агрегатное состояние
  - Количество протонов и нейтронов

### 2. Стехиометрические коэффициенты
- Панель с коэффициентами **от 1 до 9**
- **Клик** создаёт коэффициент
- **Перетаскивание** на вещество:
  - **Слева** → коэффициент перед формулой (`2NaCl`)
  - **Справа** → умножение атомов (`Na₂Cl₂`)

### 3. Рабочее поле
- **Перетаскивание** элементов для создания соединений
- **Автоматическое слияние** при пересечении объектов
- **Цветовая маркировка**:
  - 🟡 **Жёлтые** — сложные соединения (3+ элементов)
  - 🔵 **Голубые** — сплавы
  - 🔴 **Красные** — мега-соединения (6+ элементов)
- **Красная подсветка** — неудачное соединение (отталкивается)

### 4. Информация о соединениях
**Наведение** на объект показывает:
- Химическая формула
- Название вещества
- Тип (соль, кислота, оксид, сплав и др.)
- Агрегатное состояние
- Молекулярная масса
- Количество атомов
- Состав и количество каждого элемента

## Типы соединений

| Тип | Описание | Пример |
|-----|----------|--------|
| **Сплав** | 2+ металлов | Fe-Mg, Cu-Al |
| **Соль** | Металл + неметалл | NaCl |
| **Кислота** | H + O + элемент | H₂SO₄ |
| **Оксид** | Элемент + O | Fe₂O₃ |
| **Гидрид** | Элемент + H | NaH |
| **Галогенид** | Элемент + галоген | NaCl, CaF₂ |
| **Органическое** | C + H + (O,N) | C₂H₅OH |
| **Металл** | Одиночный металл | Fe, Cu |
| **Благородный газ** | He, Ne, Ar | — |

## Управление

| Действие | Результат |
|----------|-----------|
| **Клик по элементу** | Создание элемента на поле |
| **Клик по коэффициенту** | Создание коэффициента |
| **Перетаскивание** | Перемещение объекта |
| **Пересечение объектов** | Слияние в соединение |
| **Наведение** | Информационная подсказка |
| **Кнопка "Очистить всё"** | Удаление всех объектов |
